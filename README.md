# Cyber Security Portfolio

I am a cyber security graduate with hands-on experience across security operations, incident response, digital forensics, public key infrastructure, and network security. My work focuses on building, validating, and documenting real-world security controls rather than theoretical exercises.

Each repository below documents an environment I built and tested myself — the architecture, the detections or controls implemented, and the evidence that they worked.

## Core Focus Areas
- Security operations, detection engineering, and incident response
- Digital forensics and post-incident analysis
- Vulnerability management and threat detection
- Public Key Infrastructure and cryptography
- Network security, firewalls, and VPNs

## Cyber SCI Ottawa 2025
I volunteered at CyberSCI Ottawa 2025, a leading Canadian cybersecurity conference bringing together practitioners, researchers, vendors, and public sector leaders. The role involved supporting conference operations, assisting speakers and attendees, and ensuring smooth execution of technical sessions, panels, and networking events.

Through this experience, I gained direct exposure to real-world cybersecurity discussions across incident response, threat intelligence, cloud security, and critical infrastructure protection. I interacted with security professionals from government, utilities, financial services, and private industry, strengthening my understanding of how theory translates into operational security practice.

Volunteering at CyberSCI 2025 reinforced my interest in security operations and incident response, expanded my professional network, and provided insight into current threat trends, tooling, and workforce expectations in the Canadian cybersecurity landscape.
